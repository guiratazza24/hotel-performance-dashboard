# 🏨 Hotel Performance Dashboard – Business Intelligence Project

**Summer Internship 2026 | Riadh Palms Hotel – IT Department**

## 📌 Project Overview

This project was developed during my one-month summer internship at Riadh Palms Hotel, within the IT Department.

The objective was to design a Business Intelligence solution to monitor hotel performance during the summer season and transform reservation data into meaningful performance indicators.

The project follows an end-to-end BI approach, from data generation and KPI calculations to interactive data visualization.

## 🎯 Business Problem

Hotel reservation information can be scattered across different systems and tools.

This makes it difficult to monitor occupancy, room prices, revenue and booking channels efficiently.

**Main objective:** How can reservation data be transformed into reliable and readable indicators to support hotel management decisions?

## 🛠️ Technologies Used

- **Python** – Reservation dataset generation.
- **Pandas & NumPy** – Data generation and calculation checks.
- **Microsoft Excel** – KPI calculations using formulas.
- **HTML & JavaScript** – Interactive dashboard development.
- **Matplotlib** – Static data visualizations.

## 📊 Dataset

The project uses a simulated dataset containing:

- 5,898 reservations.
- 5,291 confirmed reservations.
- 499 cancelled reservations.
- 108 no-show reservations.

**Important:** All reservation data is simulated using realistic assumptions. It does not represent the actual hotel's confidential business data.

## 📈 Key Performance Indicators

| KPI | Description |
|---|---|
| Occupancy Rate | Percentage of available room nights sold |
| ADR | Average Daily Rate |
| RevPAR | Revenue Per Available Room |
| Cancellation Rate | Percentage of cancelled reservations |
| Channel Share | Distribution of reservations by booking channel |

## 🔍 Key Results

Based on the simulated summer dataset:

- Average occupancy rate: **88.7%**
- Average ADR: **122.44 TND**
- Average RevPAR: **108.65 TND**
- Total room revenue: **3.31 million TND**
- Peak performance: **August**, with 94.4% occupancy.

## 💡 Business Recommendations

1. Develop direct booking through the hotel's website.
2. Introduce dynamic pricing during lower-demand periods.
3. Monitor cancellation rates across booking channels.
4. Automate dashboard updates through a connection to the hotel reservation system.

These recommendations are illustrative and based on simulated data.

## 📊 Dashboard Features

- Daily occupancy monitoring.
